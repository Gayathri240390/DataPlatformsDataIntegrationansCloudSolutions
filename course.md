 # Data Platforms, Data Integration and Cloud Solutions

 ## Course Description

The course provides practical and theoretical knowledge of how data is collected, processed, and used in cloud-based environments. Students gain hands-on experience with modern technical solutions relevant for smart cities, connected vehicles, and industrial automation. The course also covers automation and efficiency practices central to modern DevOps.

 ## Content and Purpose

Topics covered:

- Big Data
- Data platforms
- Data integration
- Cloud solutions

Tools and methods introduced include Service-Oriented Architecture (SOA), web services, and relevant industry standards. The course purpose is to teach programming for embedded systems while applying data platforms, data integration, and cloud solutions.

 ## Learning Objectives

After completing the course, students should be able to:

### Knowledge

1. Explain different types of data and how they are stored.
2. Explain key technologies used to implement cloud platforms and solutions.
3. Explain concepts and terminology related to Big Data and cloud services.
4. Describe different types of data platforms and cloud solutions, including advantages and disadvantages.
5. Explain tools and methods used within data platforms, data integration, and cloud solutions.
6. Explain containers and virtualization.
7. Explain machine learning in embedded systems.
8. Explain technical concepts in English related to data platforms, data integration, and cloud solutions.

### Skills

9. Apply methods, tools, and technologies within data platforms, data integration, and cloud solutions to develop embedded systems.

### Competence

10. Propose and justify technical solutions for developing embedded systems based on specific requirements and contexts.

 ## Assessment

- Assessment covers course objectives 1–10.
- A written examination is used for grading (IG / G / VG):
	- IG = Fail
	- G = Pass
	- VG = Pass with Distinction

To be eligible for the written exam, the lab must be completed and submitted. The written exam will contain questions related to the lab.

 ## Re-examination

For each examination component, students have the right to participate in:

- One regular examination
- Two re-examinations

The examiner decides whether a re-examination may be completed through a correction or complementary submission.

 ## Grading Criteria

- **IG (Fail):** Course objectives not achieved.
- **G (Pass):** Complete the course and demonstrate understanding of central concepts, technologies, and methods in both the written exam and the lab.
- **VG (Pass with Distinction):** In addition to meeting G requirements, demonstrate deeper understanding by comparing, analyzing, and justifying technology choices and applying methods independently and structurally in the lab.

Key progression for VG: Explain → Compare → Analyze → Justify.

Examples of VG-level questions:

- Why choose PostgreSQL instead of MongoDB for an IoT system?
- Why use MQTT instead of HTTP?
- Why use Docker Compose locally and Kubernetes for deployment?
