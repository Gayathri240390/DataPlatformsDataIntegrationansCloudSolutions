# Cloud Architect – Individual Exercise

## Scenario

You are a **Cloud Architect** for a company. Your task is to independently analyze their data and propose a suitable storage solution.

The company has:

* Customer records containing names, email addresses, and orders
* Product images
* PDF invoices that must be stored for **7 years**
* Log files generated every minute
* A shared company folder for employees
* Backup of the entire system

---

## Classify the Data

For each type of data, state whether it is:

* **Structured**
* **Semi-structured**
* **Unstructured**

---

## Choose Storage

Choose the most appropriate storage type:

* **Block storage**
* **File storage**
* **Object storage**

---

## Hot or Cold Data?

Mark whether the data is:

* **Hot**
* **Warm**
* **Cold**

Also answer:

* Which data needs to be accessed quickly?
* Which data can be moved to cheaper storage?
* Which data needs to be stored for a long time?

---

## Backup and Recovery

Answer the following questions individually:

* Which data is most important to back up?
* What happens if the customer database is lost?
* What happens if the product images are lost?
* How quickly should the system be able to recover?
* How old can a backup be at maximum?

---

## Cost Savings

The company wants to reduce **storage costs**.

Write a proposal addressing:

* What data can be archived?
* What data can be moved to cheaper storage?
* What data must remain fast to access?
* What risk does your proposal create?
